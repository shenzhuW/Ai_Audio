# Phase 07 自制素材

`node scripts/asset-fixtures.cjs` 生成 12 秒、640×360、30 FPS、H.264 静音视频。两段自制 GPU 示意几何动画在 6 秒切换，不是实际芯片实拍或事实证据。作者为本项目测试流程，按 CC0-1.0 提供，无个人信息或第三方素材。生成参数和 SHA 见 manifest.json。

同一个原始文件建立 [0,6000) 和 [6000,12000) 两个虚拟候选；10 秒镜头显式选择循环/定格后才准备。原始视频不得修改。外部 NASA/Commons 检索及像素证据另外保留出处，不能用本夹具冒充外部结果。
