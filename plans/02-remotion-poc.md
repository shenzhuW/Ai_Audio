## 本阶段开发任务
- 独立 Render Worker：隔离运行方案、素材挂载路径、限制与日志；至少运行一次真实 Remotion Composition。
- 使用可以依法使用的本地测试视频/自行生成的几何片，叠加 SVG 动态图表、React 文字/标记层与字幕；生成 9:16 的 10 秒示例 MP4。
- 支持关键帧截图、视频元数据检测与预览播放；帧驱动动效必须确定性。
- 禁止在主 API 或同源站点内直接执行不可信 TSX；Phase 02 可先使用**可信预置组件**完成真实渲染。
- 预览画面和导出读取同一组 Props、帧率和镜头时长。

## 可验收交付物
- MP4 文件真实生成、FFprobe 能读取帧率/分辨率/持续时间；不是网页动画截图或图片假视频。
- UI 第 08 页至少能观看真实 Render Worker 导出的预览；若编译/FFmpeg 失败用户能看到可定位日志。
- 使用同样输入渲染关键帧两次，关键画面符合预期；至少有一项自动化媒体测试。
