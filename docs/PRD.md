# 产品需求文档 PRD v1.3 — AI Code Video Studio

**状态：可作为开发基线，尚待阶段实施验证**。本 PRD 继承 `DECISIONS.md`。设计领域：科技 / 财经 / 知识科普解说；语言中文优先；面向单用户工作台。

**2026-10-23 更新**：按 D-17/D-18 采用内部开发测试优先。商业许可未知或不可商用不自动阻断内部候选、分镜、渲染与 MP4 下载；保留 URL、平台、作者和已知限制，不开发商业许可审批或自动公开发布。素材访问保护边界见 DECISIONS；第三方软件/字体许可证不受该素材策略替代。

## 1. 用户任务和价值
用户希望创建一条有研究依据、叙事清晰、有真实合法素材、专业代码动画的视频，并能对每阶段产物独立修改和审批。相比“一句话直接生成 MP4”，系统必须显露研究、口播、配音、导演表、素材选择、动画代码和最终质量检查，保障事实可溯源与可控再编辑。

### 角色
- **创作者**：单用户，拥有项目、资料选择、创作审核和最终导出决定权。
- **AI 工作任务**：研究、写稿、配音、导演、素材匹配、代码动画、视觉评估。各任务通过统一接口执行，不应有隐式永久状态。

## 2. 项目入口
- 输入自由提示词、可编辑自定义视频时长（秒/分秒输入转换为秒）、画幅、语言、受众、风格、预算、可选参考资料。
- 创作起点：主题研究 / 已有口播文稿 / 从上传的资料开始。
- 目标时长属于业务期望，语音完成后的实际时长需展示偏差，用户选择文稿改写、语速调整、允许偏差。
- 请求验证：时长必须 >0 且有限数；任务实际时长上限和价格预估属于可配置额度，不允许硬编码 90 秒限制。
- 路由：创建成功进入项目总览；用户决定启动下一任务。

## 3. 核心流程与产物

### 3.1 研究（Research）
**输入**：创作需求、用户文件、选用来源范围。**动作**：生成研究计划→网页/论文/报告检索→文本/图表/图片/视频内容提取→去重/交叉核验→观点与证据组织。视频研究可做字幕识别、抽帧、时间索引，不进行正式视频裁剪。

**输出**：研究摘要、Source、Claim、MediaIndex；每条主张含来源与核验状态（未核实/有证据/冲突/作废），包含日期和数据统计口径；媒体项记录来源和已知使用限制，研究用途与内部合成用途可并存。

**用户操作**：查看原文/原片时间位置、批量选用/排除、编辑研究摘要、要求继续检索、提交并批准研究版本。

**约束**：研究来源可能是第三方观点，系统不得擅自升级为客观事实；不能虚构文献/URL/授权记录。找不到来源时文稿中标记为待验证或不使用。

### 3.2 文稿（Script）
**输入**：批准研究版本或用户自带文稿。**动作**：生成多段结构化口播文稿（开场钩子、解释、事实/案例、总结），绑定 claim IDs，估计时长和字数，允许一段覆盖多镜头。
**输出**：ScriptRevision、ScriptSegment（稳定 ID）、source bindings、estimated seconds。
**用户操作**：富文本直接编辑、增删/拖动段落、AI 局部改写、事实来源面板、差异与版本、提交/批准。
**禁忌**：因为素材看起来好看而扭曲研究结论；把模型臆造数字填到动态图表。

### 3.3 配音（Voice）
**模式 A**：AI TTS（试听声音、正式生成、字幕/词级或短语级 cue）；**模式 B**：用户上传音频（转写、人工校正与对齐）；**模式 C**：无口播（以文稿屏幕文本与自定义节奏作为时间轴）。

**输出**：VoiceAsset、VoiceTimeline、Cue、SubtitleTrack。正式动画生产前用户确定适用音频和时间基准；字幕可编辑。

### 3.4 导演分镜与素材（Director + Asset）
**流程**：批准文稿/音频 → 生成初步导演表（不机械每句一镜）→ 访问已有媒体索引 + 可访问的外部来源 → 对候选片段时间定位，优先语义相关性、内容质量、画幅、构图、清晰度和时间匹配 → 完善镜头、图层、转场、视觉样式 → 用户统一审核分镜与素材使用计划。

**每镜至少**：镜头叙事目标、对应 ScriptSegmentIDs、观众理解结果、时间锚点、镜头时长、视频/图片/图表/代码层列表、源素材引用/候选片段 in-out、转场、视觉要求、画面草图。

**用户操作**：逐镜选择/替换素材、调整建议使用区间、移动顺序、修改镜头内容和动画建议、整体提交与批准。
**素材裁剪无需用户批准**。批准的是“素材使用决策”；媒体处理器根据版本自动生成准确片段和缓存。商业许可未知或不可商用允许进入内部测试，不增加商业授权审批；仅在资源不可访问、技术无效等情况下提示更换素材或代码图解。

### 3.5 代码动画与混合制作（Motion）
- 首选已有可参数化动画组件；表达不足时生成自定义 React / SVG / Canvas TSX。
- 图片和视频作为基础图层，可在其上绘制字幕、高亮区域、数据流、箭头、镜头平移缩放、可编辑图表等。
- Frame-based 动画；SceneSpec 是场景期望的结构化表示，与实现代码分离。
- 隔离环境执行 AI 编写的代码，进行类型检查、打包、关键帧渲染、场景预览、自动发现明显问题。
- 展示镜头、图层、组件参数、AI 修改输入、渲染日志、代码高级入口、可见的版本和失败恢复。

### 3.6 成片审核与导出（Review + Export）
- 完整视频预览、时间戳评论、镜头定向反馈、AI 局部修复、质量检测报告、版本比较。
- 明确哪个问题会导致哪些版本/镜头失效，复用不受影响资源。
- 最终批准后可保存/播放/对比/下载内部测试 MP4、SRT、文稿、来源及已知限制清单和允许分发的工程包；商业许可未知或不可商用不是内部 MP4 硬门禁。商业发布的替换、授权核查与发布控制留后续。
- 不做社交平台一键发布、收费/团队账号页面。

## 4. 页面列表（与 prototype/screens 对应）
1. `01-create` 创建视频；2. `02-overview` 项目总览；3. `03-research` 研究资料；4. `04-script` 口播文稿；5. `05-voice` 配音时间轴；6. `06-storyboard` 分镜与素材；7. `07-assets` 资产管理（跨阶段工具页）；8. `08-motion` AI 动画制作；9. `09-review` 成片审核；10. `10-export` 导出成片。
详见 `UI_SPEC.md`。**10 个是页面数，不是 10 次人工审批。**

## 5. 审核与持久性
- 产物草稿编辑与批准版隔离，用户发起提交审核、批准或驳回；审批记录与输入版本固定。
- 任务异步执行并可查询进度。关闭浏览器后不得丢失状态；失败可重试或回到上一合法阶段。
- 更改已批准文稿时创建新版本；相关 VoiceCue、Shot/Scene、最终渲染视依赖受影响；原有版本完整保留。
- 单用户不是“无需权限”的同义词：API 至少通过受限会话/本地身份保护，不公开暴露上传和渲染入口。

## 6. MVP 分层
**P0 纵向真实链路**：创建项目+保存→Mock 研究/脚本→审核→基础配音（Mock/可用 Provider）→导演分镜→内部测试素材绑定→单镜/多镜 Remotion 渲染→媒体完整性检查及内部下载→可恢复任务。

**P1 真实质量提升**：真实网络检索、多模态视频时间索引、数据/事实核验、组件库扩展、视觉 AI 评审、详细增量缓存、更多可访问素材 Provider。

**P2 后续**：复杂 3D、物体跟踪/抠像、多用户、智能发布、视频复刻。

## 7. 产品级验收路径
1. 用户输入“为什么 AI 大模型需要大量 GPU”、自定义 120s、9:16，成功创建项目（120s 只是测试夹具）。
2. 有研究项目：至少能查看一个来源、一个 Claim 及状态、一个具时间码的视频候选记录（Mock 数据必须显著标识）。
3. 编辑第二段文稿、提交并批准具体版本，页面刷新数据不丢失。
4. 三种配音模式至少形成有效时间轴（无口播可用合成时间轴）；前端能展示并修改字幕片段。
5. 生成具有叙事目标、素材绑定、层级描述的导演分镜，用户修改后批准。
6. 在内部测试素材上叠加代码动画并渲染实际 MP4；成功预览，不能仅显示静态样张。
7. 修改一个镜头后显示依赖变化并重新合成，未受影响镜头内容保持一致。
8. 商业许可未知或不可商用素材能参与内部测试合成和 MP4 下载，来源/限制信息保留；不得自动公开发布。
9. 有完整的保存、恢复、审阅、错误重试与实际测试日志。

## 8. 不是成功标准的事项
UI 很像高清原型、AI 说“完成”、虚构研究报告/授权标签、只播放示例视频，均不能替代实际验收。
