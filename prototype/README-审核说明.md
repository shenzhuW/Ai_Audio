# AI Code Video Studio — v2 页面原型审核说明

统一示例项目：为什么 AI 大模型需要大量 GPU？｜自定义时长 02:00｜9:16｜6 个分镜。所有显示的来源、授权、状态、预算和数据均为界面示意，不代表已真正核验或生成。

## 十个页面
01 创建视频：允许自由输入时长；主题/文稿/资料三种起点；配音和预算选择。
02 项目总览：7 阶段流程及审核/草稿/当前阶段区分，查看依赖产物。
03 研究资料：研究报告、Claim 来源库、多模态视频时间索引，不做正式剪辑。
04 口播文稿：分段编辑、来源绑定、预计语音时长、版本与上游修改影响。
05 配音时间轴：AI/上传/无口播三模式、音频波形、词级 Cue 锚点。
06 分镜与素材：导演叙事目标、镜头图层与真实候选素材共同审核；裁剪无需审核。
07 资产管理：研究资料、候选与使用素材区分，保存源文件、时间索引及授权状态。
08 AI 动画制作：新增工作台；组件、图层、TSX 构建、预览和局部修复。
09 成片预览与审核：绑定时间码的意见、质量检查、增量修改及版本对比。
10 导出成片：MP4、SRT、文稿、源码与授权清单，未取得许可时阻止成片导出；不包含社交发布。

## 与原方案对齐
- 用户创作决策需审核，但抽帧、转码、裁剪和缓存等底层任务自动运行。
- 实际成片采用授权真实素材与代码动画叠加，避免无来源的数据图表。
- Source/Claim/Script/Cue/Shot/Asset/SceneCode 的引用和版本是后端数据协议；本文件仅展示 UI。
- 非预定范围：套餐升级、团队共享、社交账号发布、复杂 NLE 编辑器。

## 交互限制
HTML 原型已实现左侧页面导航；文本框可直接输入，但提交、审批、下载、播放器及 AI 按钮目前均为界面占位，尚未连接后端。建议审核布局、字段、命名和操作路径后交给 Codex 开发。
