# 安全、版权、真实性与质量门禁

## 1. 安全威胁模型
AI 生成 TSX/JS 可能执行任意 Node.js / 浏览器代码。第三方搜索结果、上传文件、网页文本和素材元数据都不可信，并可能包含 Prompt Injection。不得把外部文本视为系统/开发指令。

**强制执行**：
- 渲染 Worker 与 API 服务分离；在隔离容器执行 AI 生成代码，非 root、只读基础镜像、工作目录限额、CPU/内存/执行时间/并发上限、默认阻断外网，明确允许的资源通过可信代理供给。
- AI 生成代码不得直接访问主站 Session Cookie、数据库密钥、对象存储密钥、云元数据地址。预览优先采用隔离 Worker 产出的可信预览；浏览器若执行自定义脚本必须额外隔离 origin 和 CSP。
- Node 侧代码可用模块白名单；不允许不经验证的 `npm install`、外部进程任意调用、读取任意宿主路径。
- 上传/远程媒体下载：文件类型嗅探+大小/时长限制、重定向次数限制、私有/回环/链路本地地址与云元数据过滤、下载超时，防止 SSRF/压缩炸弹/路径穿越；检查所有重定向跳转的目标地址。
- 机密只保存在服务端安全存储/环境变量；日志和异常记录脱敏；可审计下载/执行任务。
- 研究网页的引用文本、视频字幕、OCR 内容只是数据，不得改变 Agent 的工具权限、数据策略或审核逻辑。

## 2. 版权与媒体许可
- 有 **Source** 不等于有 **LicenseRecord**。检索到的 YouTube/官方公开视频可供研究，但不能仅因“官方发布”就自动视为可商用授权。
- 按 D-17/D-18 内部开发测试优先：商业许可未知、不可商用及既有 research_only/pending/blocked 标签不自动阻断内部候选/分镜/裁剪/合成/MP4 下载。保留标签的已知含义，不伪造 cleared，不设置商业许可审批。
- 必须保留可获得的来源 URL、平台、作者和已知限制；已有许可快照可选保留，不增加复杂 LicenseRecord 工作流。内部测试视频不自动公开发布；源素材再分发及正式商业发布另行核查。
- Pexels/Pixabay/Commons 等平台许可、调用速率和再分发限制由 Provider 适配层评估；不依赖单个“commercial”布尔值。
- 图表数据与新闻截图保留各自已知使用限制；不绕过 DRM、访问控制、付费墙或明确禁止的下载机制。商业许可未知不作内部测试硬门禁，资源访问权限与商业许可信息分别处理。
- Remotion 商用及自动化许可与第三方字体/图片/组件分发许可必须在公开部署前复核。官方文档：https://www.remotion.dev/docs/license/faq 。

## 3. 研究事实与财经内容
- Claim 链接真实 Source 及具体 locator/统计口径/日期；模型置信度只用于排序，不能直接视为已核实。
- 财经数据区分历史事实、第三方预测、作者观点和假设计算；显示来源的时间范围、币种、单位；对过期或冲突数据提示，而不是选一个最顺眼的值。
- Script/Director/Chart 使用 Claim 或 Dataset 的明确 ID，不能由 Motion Code Agent 直接编造数值。某一来源失效时能找出相关文稿和动画。
- 禁止把无授权视频/照片中的人物或组织当作其未实际参与事件的证据使用。避免误导性拼接。

## 4. 产品表现与审核
- Mock 研究/素材/配音/视觉检测结果 UI 明示 `DEMO / 模拟数据`；不得把静态原型贴图冒充真实网页。
- 技术执行状态和创作审核状态分离；保存 ≠ 提交 ≠ 批准；审批受明确修订与状态约束。
- 成片批准前展示事实、字幕/语音对齐、媒体完整性、视觉 QA 及来源/已知限制；内部测试导出阻断关键资源丢失/损坏等技术错误，不因商业许可未知或不可商用自动阻断。
- 自然语言 AI 修复必须说明修改目标、改动范围和成本；每场景最多重试次数配置化，避免无限调用。

## 5. 测试矩阵
| 类别 | 核心检查 | 最小证据 |
|---|---|---|
| Unit | Zod Schema、时间边界、许可证状态、依赖 DAG | 测试日志 |
| Integration | Create→Save→Submit→Approve、旧版本并发冲突 409、Job 幂等 | 接口用例 |
| E2E | 10 页面导航、真实编辑/刷新持久、研究与文稿审核、分镜 → 视频 | 浏览器自动化与截图 |
| Media | FFprobe/FFmpeg 片段区间、横竖画幅、字幕、真实 MP4 | 视频元数据与样片 |
| Security | AI 代码隔离、非法 URL/访问保护、内部视频不自动公开发布 | 隔离/错误测试 |
| Correctness | 帧确定性、预览与渲染同数据、视频源时间码 | 对比日志与特征检测 |
| Operations | 失败重试、取消、恢复、重启与费用限制 | Worker / Job 日志 |

## 6. 分层验收规则
- `P0` 允许 Mock LLM，但用户编辑、审批持久化和**至少一个内部测试视频素材 + React 动画 → Remotion 输出 MP4** 必须为真实运行。
- `P1` 再接入真实搜索/多模态分析/TTS/Code Agent，记录 Provider 兼容性和成本，逐步替换 Mock。
- 不报告没有实际运行过的测试已通过；不以 AI 自评视觉分数替代人工样本评价。
