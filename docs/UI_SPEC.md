## 通用壳层
- 单用户工作台；左侧导航包含创建、总览、研究、文稿、配音、分镜、资产、动画、成片审核、导出共十个路由。每个项目有永久 projectId；刷新和直接打开深层链接可恢复上下文。
- 页面采用蓝白灰设计 Tokens：背景、表面、边线、主蓝、成功/警示/危险，统一字体层级、8px 基准间距、卡片圆角。响应式在窄屏时折叠左右栏，不丢失审核按钮。
- 标题栏提供项目标题、当前有效修订、任务/审核状态；显示演示数据必须标“模拟”。严禁在用户没批准时显示“已授权”“已核实”或“已生成”。
- 所有长任务用真实 jobId 显示进度和可恢复状态。任务进行时可离开页面。
- 一致操作：保存草稿、AI 修改、查看差异、提交审核、批准并继续、驳回修改。不同类型产物仅出现有意义的操作。
- 空/载入/失败/只读/版本冲突/权限失败/供应商未配置必须有清晰 UI；页面之间有继续上一步/下一步的导航。

## 页面目录和交互合同

### 01 创建视频 `/projects/new`（01-create.png）
**目的**：统一入口，支持从主题、已有文稿、上传资料三种起点。
**字段**：prompt（非空）、目标时长（正数，自由输入分秒，内部秒）、比例 9:16/16:9、默认 1080p、语言、视觉风格、目标观众、配音模式（AI/导入/无）、预算、上传文件。
**行为**：客户端交互校验→POST 创建→跳转项目总览；创建前显示大致预算提示但不伪造确定报价；若从已有文稿开始则可跳过研究。
**状态**：用户填错时长、上传无效文件、外部 API 未配等都要可见。
**验收**：2 分钟仅为示例数据；30 秒和 240 秒同样能保存，真正的运行限额单独配置。

### 02 项目总览 `/projects/:projectId`（02-overview.png）
**目的**：查看阶段、产物、待办、依赖、版本与资源预算。
**交互**：点击阶段跳转、点击产物进入对应修订、查看任务进度与重试、继续创作。
**状态数据**：不得写死 6 镜头或“研究已完成”；示例 fixture 为 120 秒、6 镜头；真正状态来自 API。
**验收**：项目返回上一阶段编辑后，当前阶段和待办状态与版本依赖一致。

### 03 研究资料 `/projects/:projectId/research`（03-research.png）
**目的**：研究报告、资料列表、Fact/Claim、图像和视频分析可视化。
**面板**：研究摘要、可筛选来源列表、选中来源详情、事实声明面板、视频内容时间戳/关键帧、图表数据提取视图。
**交互**：触发研究、点击来源打开原页（或视频时间点）、新增上传资料、标记采用/不采用、编辑摘要、为 Claim 标记未核实/支持/冲突、生成新修订并提交审核。
**规则**：研究中的视频只保留语义索引与抽帧，禁止自动大规模正式裁剪；缺失来源的主张不可自动“已核实”。

### 04 口播文稿 `/projects/:projectId/script`（04-script.png）
**目的**：将已审核证据转成可编辑的内容主线。
**交互**：段落编辑、重排、插入/删除；AI 仅改写选择段落；逐句查 Claim 与来源；估算时长/目标时长偏差；查看/比较版本；保存草稿→提交→批准。
**规则**：stable segmentId 不应因微小文字编辑改变；发现上游事实更改时显示受影响段落、禁止暗中覆写批准版本。

Phase 04 实际布局为左侧段落大纲/写作任务入口，中间按段正文和叙事意图，右侧估时/Claim/来源/影响；下方为差异与原修订审核。输入采用有标签的多行编辑框（不新增复杂富文本依赖），排序可键盘操作上下移按钮；段落增删、意图/节奏/引用一并真实保存。未保存编辑阻止审核和版本切换；409 保留缓冲区并提供显式重新载入。保存后审核面板同步最新版本，不应立即用旧并发版本提交。

批准、驳回、历史快照只读，fork 保留段落 ID；源研究变化显示旧引用与受影响绑定段落，替换研究后重新绑定。Mock 整体/局部改写须主动选择，任务有真实 Job ID、状态和日志；真实模型未配置不返回假文稿。预计时长只是文字估算，不显示已生成音频。

### 05 配音时间轴 `/projects/:projectId/voice`（05-voice.png）
**目的**：音频与字幕时间基准。
**交互**：AI TTS 声线/语速试听、导入音频、无口播三种方式；播放/暂停/跳转、词或短语 Cue、字幕编辑、时间偏移校正、保存并确认 VoiceTimeline。
**规则**：无口播时生成可编辑的无声时间轨，不能要求用户必须上传音频；正式动画制作前确认时间轴；时间戳需引用具体 scriptRevisionId。

### 06 分镜与素材 `/projects/:projectId/storyboard`（06-storyboard.png）
**目的**：把叙事目标翻译为画面，生成素材绑定和程序化效果方案。
**交互**：镜头新增/删除/重排、预览草图、导演目标与 viewerTakeaway、对应 scriptSegmentId / cue、图层及拟采用动画机制、按镜头搜索候选素材、查看视频建议入/出点、替换媒体/纯代码动画降级、整体提交批准。
**规则**：先初稿→按镜头检索→完善最终镜头，再让用户审核；**正式裁剪自动执行不做单独审批**。在批准分镜前允许用户修改候选源区间。

### 07 资产管理 `/projects/:projectId/assets`（07-assets.png）
**目的**：跨阶段资产目录；不是独立制作审核节点。
**分栏**：研究发现／制作候选／实际引用／上传／使用限制备注／派生缓存；按素材类型、来源、已知限制过滤。
**交互**：查看来源 URL、平台、作者（如有）与已知限制、预览原视频时间索引和联系表、搜索标签、上传、选择使用状态、查看镜头引用及时间点。已有许可凭据可查看，不设商业授权审批。
**规则**：SourceAsset 始终不变；CandidateClip 仅元数据；PreparedAsset 自动派生；按 D-17，商业许可未知或不可商用不自动阻止内部候选/分镜/渲染。不得伪称素材可商用。

### 08 AI 动画制作 `/projects/:projectId/motion`（08-motion.png）
**目的**：核心差异化工作台——代码动画叠加真实素材，并能定向修改。
**布局**：左镜头及组件目录；中实际预览（可选择帧）与属性/代码/日志 Tabs；右图层和 AI 修复建议。
**交互**：按镜头生成/重生成、查看 TSX、选图层改声明可编辑 Props、自然语言局部修改、查看编译/关键帧/安全检查、渲染低清预览与版本比较。
**约束**：浏览器不能直接在主站同源执行不可信 TSX；最初版本展示 Worker 渲染的可信 MP4/静帧。组件库优先，自由生成代码需隔离。**不要求任意源代码组件都具备可视化 Props 编辑。**

### 09 成片预览与审核 `/projects/:projectId/review`（09-review.png）
**目的**：预览整片，提交绑定时间与渲染版本的意见，AI 修复并对比。
**交互**：播放/跳转到镜头、在当前时间评论、将意见标记为待修/已修/已采纳、请求局部修复、对比前后版本、查看事实/字幕/画面 QA 和来源/限制备注、批准成片。
**规则**：每条评论记录 renderRevisionId+timeMs+shotId?；修复生成新 SceneSpec/代码/预览版本，不能直接篡改已批准成片。

### 10 导出 `/projects/:projectId/export`（10-export.png）
**目的**：使用明确修订快照导出 MP4/SRT/文稿/来源清单/许可范围内的源码与资产清单。
**交互**：选择内部测试导出规格、查看事实/视频完整性检查与来源/限制清单、启动异步导出、展示 jobId 进度与失败原因、保存/播放/对比/下载。
**禁止**：MVP 不接社交平台发布、套餐付费或多人协作，不自动公开发布内部测试视频。商业许可未知、不可商用或 pending/research_only 不作内部 MP4 硬门禁；商业发布控制留后续。

## Phase05 第05页实际实现（2026-10-24）

真实页面复用05原型的双栏卡片/模式导航：左侧声音制作、原生audio播放/seek、当前字幕、按真实位置绘制Cue条、字幕与锚点编辑；右侧Provider/声线/速度、临时试听/正式合成、真实ASR/强制对齐、偏移、确认/保存、任务审计。没有假波形。

识别草稿、实际模型对齐、人工/估算、静默计划明确区分。字幕可修改文字和起止时间并刷新保留；单段可多句/短语/词Cue。同步共享Workflow审核/拒绝/Fork/版本历史及差异，批准版输入禁用；本地dirty时禁止审核/切换，409保留缓冲并提供明确放弃后重新载入。实际音轨/模型SHA和runId可查看；云端神经TTS未配置、Mock不生成声音。实际浏览器截图和操作结果以Phase05交付证据为准。

## Phase07 actual behavior

Page07 uses the established blue/white design system: shot search/upload toolbar, candidate/library grids, true preview/contact sheet and range/binding detail, durable job list. Filters cover type, provider, discovery/index/prepared state and known restriction text. Page06 embeds the same independent per-shot binding/range editor when showing an approved director. The binding version is captured when selecting a candidate; polling cannot refresh this editing token. Another-tab changes remain visible but old confirmation returns409. Code route changes require Director Fork, and empty search is explicit; no invented result cards. Source/Prepared previews are authenticated media with byte seeking. All licensing labels remain provenance, not internal-test approval gates.
