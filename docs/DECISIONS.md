# 已确认决策与边界（2026-10-22）

## 已确认
| 编号 | 决策 |
|---|---|
| D-01 | 第一版专注科技、财经、知识科普解说视频。 |
| D-02 | 用户**自定义输入目标时长**；不强行限定为 30–90 秒。服务端有可配置预算/资源限额。 |
| D-03 | 优先 9:16，基础支持 16:9，默认 1080p；中文优先，预留多语言。 |
| D-04 | AI 配音、导入现有配音、无口播均可；正式动画开始前确认时间轴。 |
| D-05 | 研究支持文本、图片、视频、数据的多模态分析；保存证据来源和媒体时间索引。 |
| D-06 | 用户上传、合法授权素材库和官方资料是来源；**研究可参考 ≠ 可商业合成**。 |
| D-07 | 研究阶段不做批量正式剪辑；口播批准后，先初步分镜，再按镜头补搜和片段匹配，分镜确认后自动裁剪/转码；裁剪无人工审批。 |
| D-08 | 使用“授权图片/视频素材 + React/SVG/Canvas 代码动画”，可在实拍素材上叠加程序化图形；AI 图片仅为可选补充，非默认主体。 |
| D-09 | 支持从主题、已写文稿或用户上传资料三个入口创作，可跳过不必要的研究阶段。 |
| D-10 | 用户可查看、修改、提交、批准研究依据、文稿、配音方案、分镜/素材方案、成片；审批创作决策，不审批内部抽帧裁剪。 |
| D-11 | 代码动画采用“成熟组件优先 + 特殊镜头自由生成代码”的混合模式，必须隔离执行。 |
| D-12 | 自然语言修改 + 元素参数修改 + 高级源码入口；版本追踪、局部重建、审核依赖。 |
| D-13 | 首版单用户 Web 工作台，架构可扩展为多用户。 |
| D-14 | 交付 MP4、字幕、文稿、素材/事实来源清单和许可允许的源码工程；可设置任务预算与重试上限。 |
| D-15 | 开发工作主要由 Codex 执行；Codex 属于开发工具。产品运行时 Code Agent 的具体 SDK/模型以 PoC 后再确认。 |
| D-16 | 第一版**不实现**视频参考复刻。 |

## 非目标
- 社交平台账号绑定和一键发布、付费套餐、多用户实时协作、复杂 NLE、全自动万物复刻、电影级数字角色/任意 3D。
- 将原型中的假数据当作研究事实或授权证明。

## 需后续验证、但不阻碍开工的工程选项
- 具体大模型/TTS/搜索 Provider、价格、配额、API 地区可用性；第一版必须有 Provider Adapter 和 Mock。
- 代码 Agent 使用 Codex SDK、其他受支持 API 或混合方案（需沙箱和成本压测）。
- 是否引入 LangGraph；首版可以业务状态机 + 队列实现，验证复杂暂停/恢复需求后再加。
- Remotion 适用商业许可和源码分发条件在公开发布前由负责人重新确认。

## 需求变更流程
新增决策须编号、写明旧值/新值/原因/影响范围，经用户批准后更新本表、PRD、API 和相关阶段任务，不通过单次 AI 推测更改已确认需求。
